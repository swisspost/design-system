KLP real platform

KLP login widget against the real platform

No mock on this page: the widget talks to the KLP platform of the selected environment. It only answers pages served over https:// from a *.post.ch host on port 443, see readme.md next to this file.

Query parameters

  • ?env= the widget's environment, default int02
  • ?lang= language of the platform pages, default de
  • ?initialState= anonymous or authenticated
  • ?service= the widget's service, default kvm
  • ?widgets=2 renders a second widget below
