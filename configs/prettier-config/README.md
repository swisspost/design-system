# Swiss Post Design System Prettier Configuration

![Swiss Post Design System splash screen](https://github.com/swisspost/design-system/assets/1659006/e84f1fea-e666-4853-8c85-726a6bf22e6c)

Shared Prettier configuration used across the Swiss Post Design System.

## Installation

```bash
npm i -D @swisspost/design-system-prettier-config
```

## Usage

To use the configuration, include it in your `package.json` file:

```json
{
  "prettier": "@swisspost/design-system-prettier-config"
}
```
