# Swiss Post Design System Stylelint Configuration

![Swiss Post Design System splash screen](https://github.com/swisspost/design-system/assets/1659006/e84f1fea-e666-4853-8c85-726a6bf22e6c)

Shared Stylelint configuration used across the Swiss Post Design System.

## Installation

```bash
npm i -D @swisspost/design-system-stylelint-config stylelint
```

## Usage

To use the configuration, extend it in your Stylelint config file, for example `.stylelintrc`:

```json
{
  "extends": "@swisspost/design-system-stylelint-config"
}
```
