<h3>Which Figma seat suits me?</h3>

Choose a seat based on how you need to work with Figma.

<h4>Figma «Full Seat»</h4>

For designers, product managers and team members who actively create designs, prototypes and collaborate within the team.

<h4>Figma «Dev Seat»</h4>

For developers working on the implementation of designs in code. Inspect designs and access the specifications needed to build them.

<h4>Figma «View Seat»</h4>

For users who only need to view and give feedback on existing design projects, without editing or creating content.

<h4>Figma «Guest Seat»</h4>

For guests who need temporary access to a project. Guests must be activated by an administrator.
