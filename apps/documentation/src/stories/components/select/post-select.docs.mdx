<div className="lead">A non-native select component for choosing one option from a list.</div>

Use `<post-select>` with `<post-select-option>` elements. By default, each option displays its
`value` as text, with an optional `icon`. To customize an option, place markup in its default slot;
that content replaces the standard text and icon inside the option.
