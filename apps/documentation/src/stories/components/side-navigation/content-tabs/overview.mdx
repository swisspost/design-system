## Adding the trigger to the header

To let users open the side navigation on smaller screens, add the `<post-side-navigation-trigger>` component to the `slot="side-nav"` of the [application header](/?path=/docs/27a2e64d-55ba-492d-ab79-5f7c5e818498--docs#application). It is placed to the left of your application title.

<Source of={SideNavigationStories.HeaderTrigger} />

## Page structure

In order for your page content to not be partially hidden by the side navigation on desktop, the `.main-container` class needs to be added on the outside wrapper of your page's content.

## Navigation content

The default slot holds the navigation content. It must be a `<nav>` landmark with a descriptive `aria-label` and `<ul>`/`<li>` lists for the items. Nested levels are nested `<ul>`s.

For the content rules, such as the number of levels and the use of icons, see the Usage tab.
