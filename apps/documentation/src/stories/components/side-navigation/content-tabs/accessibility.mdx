### Links and disclosure buttons

- Use `<a>` for links and a `<button>` inside `<post-collapsible-trigger>` for collapsible sections. A link navigates, a button discloses; never nest one inside the other.
- Mark the current page link with `aria-current="page"`.

### Focus management

- On mobile, focus moves into the navigation when the dialog opens and returns to the trigger when it closes.
- The rest of the page is inert while the dialog is open.
