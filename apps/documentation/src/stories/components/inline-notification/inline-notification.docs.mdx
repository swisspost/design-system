<div className="lead">
  Inline notifications show up in task flows, to communicate the users the status of an action or
  system. It can also be used as a persistent element on the page to communicate information which
  needs higher attention than regular text.
</div>

Use an inline notification when the message relates to the current task, requires no action on the user's part, and needs to remain visible at all times. It is also the appropriate choice when the user must take action and the decision is required to proceed, but is not part of the intended flow (for example, a validation error in a form).
