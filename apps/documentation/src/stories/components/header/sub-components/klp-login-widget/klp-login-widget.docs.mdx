## Setup

Set `environment` to select the platform (`prod` uses `n.account.post.ch`) and `service` to your
application's registered service name. Set `app` if your registered app name differs, and
`in-iframe` when the application runs in an iframe. Your page must use an allowed `post.ch` origin.
If you use a Content Security Policy, allow the platform in `connect-src` for `https:` and `wss:`.

## Initial state

Before the signed-in state is known, the widget shows an avatar without initials. Set `initial-state`
when your page already knows the visitor's authentication state, for example during SSR.

<Canvas of={KlpLoginWidgetStories.InitialState} />

## Unread messages

The Messages entry shows the unread count, and the avatar shows a dot when the count is greater than
zero. Use the `Unread messages` control above to preview the badge.

## Accessibility

Provide accessible text in the page's language:

- `text-current-user` labels the avatar; `{user}` is replaced with the user's full name.
- `text-user-links` labels the user menu.
- The `text-access-user-links` slot labels the button that opens the menu. It is translated by
  default.

The unread count is announced with `text-unread-messages`, which is translated by default.
