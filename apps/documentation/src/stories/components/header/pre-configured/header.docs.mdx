## Language switch overrides

Override the language switch links with custom URLs. This is helpful when your application contains sub-pages and you want users to stay on the same sub-page when they change language.

<Source code={htmlSample} language="html" />

Add `<link rel="alternate">` tags to the `<head>` of your page. When present, alternate links take priority over the Portal config URLs. If no alternate link exists for a given language, the header falls back to the config value.

Supported `hreflang` values are `de`, `fr`, `it`, and `en`.

### Dynamic updates

Update the alternate link URLs on every route change to ensure that the language switch always points to the correct page.
