The `<post-breadcrumbs>` is a container for `<post-breadcrumb-item>` components, used to display a navigational trail, showing the user's location within the app and enabling quick access to parent pages.

By default the root breadcrumb shows a home icon, with `text-home` used only as its accessible label. Set `home-text` to `true` to show `text-home` visibly instead — useful when the root should link to a segment's own home page (e.g. "Private customers", "About us") rather than the generic site root.

<Canvas of={BreadcrumbsStories.CustomHomeText} sourceState="shown" />

</post-tab-panel>

<post-tab-panel for="client-side-routing" class="pt-24">

To enable client-side routing (e.g. Next.js, Angular Router), slot your own anchor instead of using the `url`/`home-url` properties: use the default slot for `<post-breadcrumb-item>`, or the `home` slot for the root item of `<post-breadcrumbs>`. Both components detect the slotted `<a>` and stop rendering their own, leaving your link's click handling untouched.

<post-banner type="info">
  <p>
    Slotting your own `<a>` makes the `url`/`home-url`, `label`, and `description` properties ineffective. Set these attributes directly on the slotted `<a>` instead, including `aria-current="page"`, which is not applied automatically.
  </p>
  <p>
    The `selected` property still works as expected: it applies the correct visual styling and controls the item's position in the breadcrumb trail.
  </p>
</post-banner>
