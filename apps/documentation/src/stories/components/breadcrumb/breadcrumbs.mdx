### Routing with Client-Side Frameworks

To enable client-side routing, provide your own link through a slot. This works with routing
libraries such as Next.js and Angular Router. Use the default slot for regular
`<post-breadcrumb-item>` elements. Use the `home` slot for the root item of `<post-breadcrumbs>`.

The component detects the slotted link and leaves it unchanged, allowing the routing library to
handle navigation. The `url` and `home-url` properties are ignored when a slotted link is used.
  

<post-banner type="info">
  <ul className="list-bullet"><li>
    For regular breadcrumb items, the slotted link must be a direct child of
    `<post-breadcrumb-item>`. For the root breadcrumb, the slotted link must be a direct child of
    `<post-breadcrumbs>` and use the `home` slot. In both cases, if the link is wrapped in another element, it won't be
    detected and the component will fall back to rendering its own internal link.
  </li>
    <li>
      When a link is slotted, the component does not automatically apply the `label`, `description`,
      or `aria-current` attributes. To make the link accessible:
      (a) give it an accessible name through its text content or `aria-label` and (b) add
      `aria-current="page"` if it represents the current page.
    </li>
  </ul>
</post-banner>
